## 3. 27 句变体（`voice/`，48 kHz 单声道 96 kbps）

用本地 whisper（`mlx-community/whisper-small-mlx`）逐句听校后，只把**语义与当下情境一致**的句子放进轮播池；
被抓时不能突然说“钥匙呢”，预警时不能说“我进来了”。

| 池 | 进池 | 听校台词 | 未进池（保留文件，待手工 A/B） |
|---|---|---|---|
| `warn` | 01 / 05 / 06 | 有人过来了 / 你在干嘛 / 听见你了 | 02 脚步停了、03 别在客厅晃、04 我进来了（预警期说“进来了”会预告错位） |
| `study` | 01 / 03 / 04 / 05 | 不是让你写作业吗 / 谁让你起来的 / 作业写完了吗 / 抬头干什么 | 02 笔呢（语气太轻，不像抓现行） |
| `tv` | 01 / 02 / 03 / 05 | 九点前不准开电视 / 谁让你开电视的 / 节目表你没看 / 眼睛看哪儿呢 | 04 回屋坐好（是命令不是质问） |
| `escape` | 01 / 05 | 让你倒垃圾还在磨蹭 / 垃圾倒了没有 | 02 钥匙呢、03 门开那么大干什么、04 下楼（都是窗口期的话，不是被抓台词） |
| `reading` | 01 / 02 / 03 | 我在跟你说话你在看什么 / 把纸放下 / 谁让你翻那些的 | — |
| `timeOk` | `parent_time_ok` / `checkb_03` | 到点了 / 到点了！ | — |
| `timeEarly` | `parent_time_early` / `checkb_02` | 还没到时候 | `checkb_01`（听校为“这就到点了”，语义与错时冲突，暂不进池） |

自检：`npm test` 里的 `tests/audio-delivery.test.mjs` 校验池子只引用真实存在的句子（并钉住上面“不进池”的排除项）；
`npm run audio:check`（需先 `npm run serve`）在真实 Chromium 里逐个 fetch + decode 全部 49 个 mp3。

播放策略：每个池洗牌后顺序取，**同一句不会连着出现两次**；整句缺失时退回固定槽位（`parent_warn.mp3` 等），
再失败则用原有的 WebAudio 合成回退。低恐怖模式沿用 `vol()`，音量减半。
